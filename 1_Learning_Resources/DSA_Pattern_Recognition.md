# DSA Pattern Recognition Table

| Pattern                  | Problems Needed | When to Use                               | Core Idea                        | Hints to Identify Pattern                                                                                  |
| ------------------------ | --------------- | ----------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Two Pointers             | 8–10            | Sorted arrays, pairs, palindromes         | Move pointers intelligently      | Problem asks for pairs, triplets, or subarrays; often sorted input; need to compare or move from both ends |
| Sliding Window           | 10–12           | Subarray / substring / longest / shortest | Expand & shrink window           | Find max/min/longest/shortest subarray/substring; contiguous elements; fixed or variable window size       |
| Hashing (Set/Map)        | 10–12           | Duplicates, frequency, lookup             | Store & retrieve fast            | Need to check existence, count, or frequency; fast lookup; avoid nested loops for search                   |
| Partitioning             | 5–6             | Rearrange / segregate / move elements     | Place elements in correct region | Move elements to different sides/regions; segregate by value or property; in-place rearrangement           |
| Binary Search            | 12–15           | Sorted arrays / search space              | Halve the search space           | Search in sorted data; minimize/maximize value; answer lies in a range; logarithmic time needed            |
| Sorting-Based            | 6–8             | When order matters / preprocessing        | Sort + then solve                | Need to process in order; easier after sorting; compare adjacent elements                                  |
| Heap (Priority Queue)    | 8–10            | k-th element, top k                       | Maintain partial order           | Find k-th largest/smallest; maintain running min/max; need partial sorting                                 |
| Prefix Sum               | 6–8             | Subarray sum / cumulative                 | Precompute sums                  | Many sum queries; need fast range sum; cumulative totals                                                   |
| Intervals                | 5–7             | Overlapping ranges                        | Sort + merge                     | Given intervals/ranges; merge, find overlaps, or gaps; timeline problems                                   |
| Recursion / Backtracking | 10–12           | Combinations / permutations               | Explore all possibilities        | Generate all combinations/permutations; choices at each step; try all paths                                |
| Strings (Mixed)          | 10–12           | Substrings / pattern match                | Sliding window + hashing         | Manipulate substrings; pattern search; anagrams; string-specific tricks                                    |
| Greedy                   | 8–10            | Optimal local choice                      | Take best immediate decision     | Make best choice at each step; no backtracking; locally optimal leads to global                            |
| Bit Manipulation         | 5–7             | XOR / binary tricks                       | Work at bit level                | Work with bits; use AND/OR/XOR; powers of two; bit masks                                                   |
| Dynamic Programming (DP) | 15–20           | Overlapping subproblems                   | Store & reuse results            | Optimal substructure; overlapping subproblems; recursive + memoization/tabulation                          |
| Graphs (BFS/DFS)         | 12–15           | Traversal / connectivity                  | Explore nodes                    | Nodes/edges; traverse or search; find paths, cycles, components                                            |
| Trees                    | 12–15           | Hierarchical problems                     | Recursive traversal              | Parent-child structure; traverse up/down; subtree or ancestor queries                                      |
