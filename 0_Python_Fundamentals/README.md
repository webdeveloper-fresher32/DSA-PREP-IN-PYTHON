# Python Fundamentals Practice Set

Build fluency in Python syntax and develop the problem-solving mindset needed for DSA.

## How to Use This
- Work through topics **in order** — each builds on the previous.
- Within each topic, do **Easy → Medium → Hard**.
- Write your solution, then check it works with the test cases at the bottom.
- Focus on: clean variable names, no redundant logic, clear thinking.

## Topic Roadmap

| # | Topic | Key Skill |
|---|-------|-----------|
| 01 | Variables & Data Types | Type awareness, casting, mutability |
| 02 | Loops | Iteration patterns, nested loops, break/continue |
| 03 | Conditionals | Decision logic, edge cases |
| 04 | Functions | Decomposition, return values, scope |
| 05 | Lists | Indexing, slicing, common operations |
| 06 | Strings | Manipulation, searching, formatting |
| 07 | Dictionaries | Key-value logic, frequency counting |
| 08 | Sets | Uniqueness, intersection, union |
| 09 | Recursion | Base cases, call stack thinking |
| 10 | Mixed Practice | Combining everything — closest to real DSA |

## Difficulty Guide
- **[E]** Easy — tests syntax understanding
- **[M]** Medium — requires some logic and planning
- **[H]** Hard — multi-step thinking, closest to interview style
